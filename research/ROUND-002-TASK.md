## 三、任务一：修复独立无捕获对照

问题编号 ISSUE-001，优先级 P0。

当前 verify.py 的两次真实 ATLIF 前向均发生在 Surrogate.forward 捕获包装开启的状态下，不能证明捕获开启与关闭时原模型行为完全一致。

请新增独立对照。

数学定义：

m[t] = tau*u[t-1]+x[t]

s[t] = H(m[t]-theta)

u[t] = (1-s[t])*m[t]

o[t] = theta*s[t]

对相同输入、相同模块参数、相同初始状态分别执行：

G0：未包装 Surrogate.forward 的原始 ATLIF。

G1：开启膜电位捕获的 ATLIF。

G2：恢复原始 Surrogate.forward 后再次运行。

要求：

- 三组使用相同权重、阈值、tau、T、输入和数值精度。
- 使用独立等价模块或完整恢复全部相关内部状态。
- 使用 eval() 和 no_grad()。
- 不改变 Baseline 原始前向算法。
- 检查完整输出张量和二值脉冲逐元素一致性。
- 对相同条件检查 FR、脉冲计数。
- 检查包装函数在正常运行和异常情况下均能恢复。
- 检查 update_value 等内部状态是否受到诊断污染。
- 合理覆盖原 EXP-001 的实际 ATLIF 测试条件，包括边界、静默、每步发放及多维输入。
- 完整数值一致性容差继续采用 float32 1e-5；脉冲状态必须逐元素一致。
- 不允许通过放宽容差获得通过结果。

若对照失败，记录并修复诊断实现，不修改 Baseline 核心机制。

如适用，可通过下一时刻膜电位反推上一时刻状态：

仅在 tau 非零且具备相应真实观测时使用。

对于 tau=0、最后时间步及不可独立观测的状态，报告适用边界，不得虚构实际采集结果。

原 R1、R2 公式保持不变：

X = sum_t(x[t])

O = sum_t(theta*s[t])

D_leak = (1-tau)*sum_t(u[t-1])

D_reset = sum_t(s[t]*(m[t]-theta))

D_res = u[T]-u[0]

R1: X = O+D_leak+D_reset+D_res

R2: Delta_O = -Delta_D_leak-Delta_D_reset-Delta_D_res

## 八、理论与代码差异的处理决定

已经确认原始 Surrogate.backward 使用：

grad_input = upstream*g

grad_thre = -mean(upstream*g*g)

论文 Eq.13 使用的局部阈值替代梯度为 -g。

本轮不修改该规则。

因为当前主线研究前向动力学，而不是阈值梯度优化。

已确认阈值还接受优化器之后的手动更新。

手动调节对 Batch 维度求和，对其他维度平均并沿时间归一化。

因此正式复现前需要明确：

- 原始 Batch Size。
- 梯度累积步数。
- 阈值更新与优化器学习率关系。
- 阈值是否保持正值。
- eval() 期间 update_value 是否累积。
- 如何防止诊断状态污染正式训练。

不要通过修改 Baseline 原始训练规则解决尚未经理论批准的问题。
