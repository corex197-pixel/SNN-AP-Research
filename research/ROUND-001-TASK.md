## 二、Baseline 研究背景

Baseline 论文：

Activity Pruning for Efficient Spiking Neural Networks

Tong Bu, Xinyu Shi, Zhaofei Yu, NeurIPS 2025.

论文主页：

https://proceedings.neurips.cc/paper_files/paper/2025/hash/fa12d67b5939c37ea8a4659c31a08d2c-Abstract-Conference.html

原作者公开代码：

https://github.com/putshua/Activity-Pruning-SNN

注意：上述为公开上游仓库，不一定是用户实际工作的目标仓库。

该方法主要研究活动剪枝，即减少 SNN 的脉冲发放事件，而非直接永久删除权重。

AT-LIF 的核心机制包括：

1. 自适应发放阈值。
2. 使用阈值缩放二值脉冲输出。
3. 阈值相关三角形替代梯度。
4. 阈值活动正则化与任务学习相结合。

原文公式：

```text
Eq. (2):
m[t] = tau * u[t-1] + x[t]

Eq. (3):
s[t] = H(m[t] - theta)

Eq. (4):
u[t] = (1 - s[t]) * m[t]

Eq. (10):
o[t] = theta * s[t]

Eq. (11):
x_i[t] = sum_j(w_ij * o_j[t]) + b_i

Eq. (12):
Delta_theta = eta * (
    dL_task/dtheta
    + lambda_theta * sum_t(s[t] * do[t]/dtheta)
)

Eq. (13):
do[t]/dm[t] = -do[t]/dtheta
             = max(1 - abs(m[t]-theta)/theta, 0)
```

Eq. (12) 的符号应结合实际梯度更新方向理解，Eq. (13) 是替代梯度规则而非普通真实导数。

原文对应位置：

- 第3页，第2.2节：LIF 动力学。
- 第5页，第3.2节：AT-LIF 模型。
- 第6页，第3.3节：阈值适应及替代梯度。
- 第7页，第3.4节：稳定性分析。
- 第8页，Table 1：活动剪枝实验。
- 第10页，Table 3：消融实验。

## 三、本轮科学问题

Q-001：

提高发放阈值以减少活动时，AT-LIF 使用阈值缩放输出能否充分补偿膜电位动力学导致的累计输出偏差？

Q-002：

阈值改变可能同时改变脉冲时序、重置状态及神经元静默比例。这些因素可能是任务损失变化的竞争性解释。

本轮优先诊断 Q-001，不单独实现新的时序剪枝方法。

## 四、独立理论公式

以下公式属于本项目 THEORY v0.1.0 的独立代数推导，不是原论文的新定理。

定义：

```text
X = sum_t(x[t])

O = sum_t(theta * s[t])

D_leak = (1 - tau) * sum_t(u[t-1])

D_reset = sum_t(s[t] * (m[t] - theta))

D_res = u[T] - u[0]
```

根据原始 AT-LIF 动力学：

```text
R1:
X = O + D_leak + D_reset + D_res
```

对于相同有效输入序列、相同初始状态、相同泄漏系数，仅改变发放阈值的两条神经元轨迹：

```text
theta_alpha = alpha * theta_0

Delta_O = O_alpha - O_0
Delta_D_leak = D_leak_alpha - D_leak_0
Delta_D_reset = D_reset_alpha - D_reset_0
Delta_D_res = D_res_alpha - D_res_0

R2:
Delta_O = -Delta_D_leak
          -Delta_D_reset
          -Delta_D_res
```

成立前提：

- 离散膜电位动力学与上述公式一致。
- 硬重置至零。
- theta > 0。
- 单个样本仿真期间阈值固定。
- 输出为 theta * s。
- 正确捕获神经元实际有效输入和初始状态。

注意：

- 允许负输入及负膜电位。
- D_leak 和 D_res 可能为负。
- D_reset 在正阈值且正常发放条件下非负。
- 各动力学项可能相互抵消。
- 不得把这些变量称为物理能量。
- 不得把累计输出偏差直接称为任务信息损失。
- 如果实际代码采用不同充电、重置、截断或初始状态规则，必须记录差异并暂停不适用的机制统计。
- 不允许为了满足公式而偷偷修改原始 Baseline。

## 五、科研假设

### H-001：动力学补偿偏差假设

状态：UNTESTED。

在冻结训练权重、固定有效输入的条件下，提高 AT-LIF 发放阈值并有效降低发放率时，可能产生具有实际幅度的累计输出偏差。

预期可观测现象：

- 发放率下降。
- 累计输出发生变化。
- 动力学分解项发生变化。
- R2 能够解释累计输出变化。

支持或反对该假设的条件见后续实验门槛。

### H-002：累计输出偏差的任务影响假设

状态：UNTESTED。

当提高阈值导致任务损失增加时，累计输出偏差可能是部分性能下降的可干预原因。

如果在不改变受干预模块脉冲状态和发放时序的条件下，恢复部分参考累计输出能够缓解任务损失，则为该假设提供初步支持。

竞争性解释：

- 脉冲时序变化。
- 神经元完全静默。
- 一般幅值调节。
- 下游非线性响应。
- 网络层敏感性。
- 训练后权重适应。

不能将预期结果作为必须产生的结果。

## 七、EXP-001：动力学恒等式验证

### 7.1 实现独立参考模拟器

优先采用 CPU float64 实现，不修改原神经元算法。

逻辑伪代码：

```python
u = u0
X = 0
O = 0
D_leak = 0
D_reset = 0

for t in range(T):
    D_leak += (1 - tau) * u
    m = tau * u + x[t]
    s = spike_rule(m, theta)
    o = theta * s

    X += x[t]
    O += o
    D_reset += s * (m - theta)

D_res = u - u0
residual = X - O - D_leak - D_reset - D_res
```

### 8.5 张量规范

```text

```

或：

```text

```

其中：

- B：Batch 维度。
- N：每个样本的神经元状态数量。

采集：

```text

m[t]       重置前膜电位
```

从实际神经元内部获取状态，或通过已验证的等价 replay 获取，不得仅根据输出张量猜测内部膜电位。

### 8.6 评价指标

指标一：平均发放率。

```text
FR_alpha = mean(s_alpha)
```

均值覆盖样本、时间及该模块所有神经元状态。

```text
R4:
R_FR = (FR_ref - FR_alpha) / FR_ref
```

参考 FR 为零时记录 NA。

指标二：累计输出偏差。

```text
O_ref[b,i] = sum_t(o_ref[t,b,i])
O_alpha[b,i] = sum_t(o_alpha[t,b,i])

R5:
E[b] =
    sum_i(abs(O_alpha[b,i] - O_ref[b,i]))
    /
    sum_i,t(abs(x_ref[t,b,i]))
```

先沿时间维度计算每个神经元的累计输出，再计算绝对差异，不能先在神经元维度求和。

分母为零时标记 NA 并统计出现次数。

另外报告以参考累计输出绝对总量为分母的辅助指标，分母为零时同样标记 NA。

指标三：动力学分解。

逐样本、逐神经元计算：

```text
D_leak
D_reset
D_res
Delta_D_leak
Delta_D_reset
Delta_D_res
Delta_O
```

报告有符号均值、绝对值均值、中位数、P90、P95。

保留 R1、R2 恒等式检查结果。

指标四：脉冲状态翻转率。

```text
R6:
F_flip = mean(s_alpha != s_ref)
```

分开报告 1->0 和 0->1 的事件数及比例。

指标五：新增静默比例。

```text
K_ref[b,i] = sum_t(s_ref[t,b,i])
K_alpha[b,i] = sum_t(s_alpha[t,b,i])

R7:
F_silent =
    count((K_ref > 0) AND (K_alpha == 0))
    /
    count(K_ref > 0)
```

分母为零时标记 NA。

指标六：任务性能变化。

```text
R8:
Delta_loss[b] = loss_alpha[b] - loss_ref[b]

Delta_accuracy = accuracy_alpha - accuracy_ref
```

使用逐样本交叉熵和分类正确性，保留配对索引。

如额外计算 SOPs，必须记录计数定义，区分活动事件与有效非零连接，不得将其描述为硬件实测能耗。

### 8.7 统计方法

- 固定相同诊断样本。
- 保留逐样本配对记录。
- 对主要指标使用2000次样本级配对 Bootstrap。
- Bootstrap 随机种子：2027。
- 报告95%百分位置信区间。
- 对 R_FR 等比例指标，在每次重采样后重新计算整体分子和分母。
- 不将神经元数量当作独立样本数量。
- 不将样本级置信区间解释为独立模型训练种子之间的稳定性。
- 明确报告 NA 数量及排除范围。

### 8.8 H-001 预设进入门槛

主要验证条件：中部模块、alpha=1.5。

以下条件同时满足，允许进入 EXP-003：

1. R_FR >= 0.20。
2. mean(E) >= 0.05。
3. mean(E) 的95% Bootstrap CI 下界 > 0.05。
4. R1 和 R2 数值检查通过。
5. 相同有效输入与 alpha=1.0 对照检查通过。
6. G1 相对于参考模型的平均交叉熵增量 >= 0.02 nats，且配对95% CI 下界 > 0。

条件6仅用于判断是否存在足够的任务损失供 EXP-003 诊断，不是 H-001 本身成立的必要条件。

若活动有效下降但 mean(E) 的95% CI 上界 < 0.05，则报告当前条件下不支持具有实际幅度的 H-001。

若干预强度不足、样本不足、置信区间过宽或指标无效，则报告证据不足。

其他 alpha 和其他层属于补充探索。

不得事后修改主要验证条件。

## 九、EXP-003：累计输出补偿反事实诊断

### 9.1 实验性质

本实验是诊断性反事实干预，不是拟发表的新算法。

禁止将参考输出引导的幅值补偿作为独立可部署方法报告。

只有 EXP-002 达到预设进入门槛且资源允许时才执行。

### 9.2 实验分组

```text
G0:
原始阈值，原始输出。

G1:
theta = 1.5 * theta_ref，
原始 AT-LIF 输出。

G2:
theta = 1.5 * theta_ref，
参考累计输出引导的幅值补偿。

G3:
theta = 1.5 * theta_ref，
随机置换 G2 的补偿系数。
```

仅干预 EXP-002 的主要模块。

所有组使用同一模型权重、同一样本和同一初始状态。

### 9.3 补偿公式

对每个样本 b、神经元 i：

```text
O_ref[b,i] = sum_t(o_ref[t,b,i])
O_alpha[b,i] = sum_t(o_alpha[t,b,i])

K_ref[b,i] = sum_t(s_ref[t,b,i])
K_alpha[b,i] = sum_t(s_alpha[t,b,i])

eligible[b,i] =
    (K_ref[b,i] > 0) AND
    (K_alpha[b,i] > 0)
```

补偿系数：

```text
R10:

if eligible[b,i]:
    c[b,i] = clip(
        O_ref[b,i] / O_alpha[b,i],
        0.25,
        4.0
    )
else:
    c[b,i] = 1.0
```

补偿输出：

```text
R9:
o_cf[t,b,i] = c[b,i] * o_alpha[t,b,i]
```

正阈值条件下，eligible 区域的 O_alpha 理应为正。

遇到不符合该条件的数值异常应报告，不得任意添加 epsilon 掩盖错误。

c 的逻辑维度为 [B,N] 或与实际空间状态对应的 [B,C,H,W]。

沿时间维度广播，不沿错误的 Batch 或通道维度广播。

系数在无梯度模式下计算。

只修改传递给下游网络的输出，不改变受干预神经元自身的 s、m、u 和重置轨迹。

如果模块输出同时被用于自身重置或反馈计算，必须找到独立的下游传递边界；无法隔离时暂停实验。

### 9.4 随机补偿对照

G3 在同一样本、同一个模块内部，仅对 eligible 区域中的补偿系数做固定种子的随机置换。

随机种子：2028。

不改变系数分布，不使用标签。

不符合 eligible 条件的位置保持 c=1。

若可置换元素少于2个，记录该样本无法形成有效置换对照。

### 9.5 必须通过的对照检查

G1、G2、G3 的受干预模块：

```text
s_G1 == s_G2 == s_G3
```

要求完整脉冲张量逐元素一致。

同时验证该模块自身膜电位及重置轨迹一致。

G2、G3 不允许新建脉冲或删除原有脉冲。

下游网络的脉冲及膜电位状态允许自然变化。

报告：

- eligible 神经元比例。
- 原参考活动神经元中的补偿覆盖率。
- 系数截断比例。
- 补偿系数分布。
- 新增静默比例。
- 未能恢复累计输出的原因。

注意：R1、R2 适用于原始神经元内部输出；反事实输出是额外下游干预，不要求其继续满足原始动力学平衡式。

### 9.6 评价指标

G0、G1、G2、G3 均报告：

- 逐样本交叉熵。
- 分类准确率。
- 主要模块累计输出偏差。
- 主要模块 FR。
- 主要模块脉冲状态一致性。

定义：

```text
R11:
R_E = (mean(E_G1) - mean(E_G2)) / mean(E_G1)
```

以及：

```text
R12:
R_loss =
    (mean(loss_G1) - mean(loss_G2))
    /
    (mean(loss_G1) - mean(loss_G0))
```

任务损失增量非正或过小时，不使用 R_loss，标记 NA。

不得先逐样本计算恢复比例再简单平均。

同时报告：

```text
Gain_G2_vs_G1 = mean(loss_G1 - loss_G2)

Gain_G2_vs_G3 = mean(loss_G3 - loss_G2)
```

使用2000次固定种子的样本级配对 Bootstrap。

每次重采样重新计算组均值及比例指标。

若比例指标的分母在 Bootstrap 中非正，应报告无效重采样比例，不能据此生成误导性的稳定置信区间。

### 9.7 H-002 预设推进门槛

以下条件同时满足，报告“达到初步支持门槛”，但不自行更新最终科学结论：

1. G1 的交叉熵增量达到 EXP-002 进入门槛。
2. R_E >= 0.50。
3. R_loss >= 0.25。
4. Gain_G2_vs_G1 的95% CI 下界 > 0。
5. Gain_G2_vs_G3 的95% CI 下界 > 0。
6. G1、G2、G3 的受干预模块脉冲状态一致。
7. 指标计算与数据完整性检查通过。

若累计输出偏差得到充分恢复，但 R_loss 的有效95% CI 上界仍 < 0.25，则报告当前干预条件下的反对证据。

若补偿覆盖率不足、静默神经元过多、任务损失增量过小、统计不稳定或随机对照无法形成，则报告证据不足。

如果 G2 和 G3 均有效且差异不明确，则不能证明参考累计输出恢复机制具有特定作用。

所有上述结论仅针对当前模型、当前干预模块和当前诊断样本。
