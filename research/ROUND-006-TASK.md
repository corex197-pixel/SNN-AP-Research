## 三、科学问题与实验目标

Q-001：

在已经充分训练的AT-LIF网络中，额外提高局部发放阈值、进一步降低活动时，阈值幅值缩放是否会产生具有实际幅度的累计输出补偿偏差？

H-001：

在固定有效输入、冻结权重、相同初始膜电位条件下，提高阈值并有效减少发放时，可能产生具有实际幅度的累计输出偏差。

H-002：

如果上述干预使任务损失增加，那么在保持受干预模块脉冲状态及时间位置不变的条件下，恢复部分累计输出可能缓解部分任务损失。

竞争性解释：

- 脉冲时序改变。
- 新增静默神经元。
- 下游网络非线性。
- 一般性幅值调整。
- 冻结权重后无法进行端到端适应。
- 不同模块敏感性差异。

本轮只能检验额外阈值扰动下的动力学和任务效应。

不得将实验结果直接解释为原训练阈值下必然存在严重动力学缺陷，也不得宣称更强稀疏训练一定无法自行补偿。

## 七、原始动力学与独立理论公式

原论文动力学：

m[t] = tau*u[t-1]+x[t]

s[t] = H(m[t]-theta)

u[t] = (1-s[t])*m[t]

o[t] = theta*s[t]

实际ATLIF使用 m>=theta 的发放条件。

实际ATLIF每次forward内部膜电位初始为0。

本项目独立理论公式：

X = sum_t(x[t])

O = sum_t(theta*s[t])

D_leak = (1-tau)*sum_t(u[t-1])

D_reset = sum_t(s[t]*(m[t]-theta))

D_res = u[T]-u[0]

R1:

X = O+D_leak+D_reset+D_res

阈值干预：

theta_alpha = alpha*theta_ref

固定有效输入、初始状态及tau时：

R2:

Delta_O = -Delta_D_leak-Delta_D_reset-Delta_D_res

以上是代数恒等式，不是任务信息损失或物理能量守恒公式。

D_leak和D_res可以为负，各项可能抵消。

不得将动力学分解项的绝对值之和称为精确累计输出损失。

## 九、EXP-002：真实网络阈值扰动实验

实验条件：

alpha = 1.0, 1.25, 1.5, 2.0

以原阈值alpha=1.0作为参考。

先完成主要中部模块。

其他模块为补充探索，资源不足时可以不执行。

对每个样本及每个神经元状态位置，先沿时间维度累计，再进行空间和样本统计。

### 9.1 活动变化

R4：

FR = total_binary_spikes / total_neuron_time_states

R_FR = (FR_ref-FR_alpha)/FR_ref

参考FR为0时记录NA。

同时保存每个样本的spike_count、neuron_time_states等原始计数，以便独立复算整体比例和Bootstrap。

### 9.2 累计输出偏差

O_ref[b,i] = sum_t(o_ref[t,b,i])

O_alpha[b,i] = sum_t(o_alpha[t,b,i])

I_abs[b] = sum_i,t(abs(x_ref[t,b,i]))

R5：

E[b] = sum_i(abs(O_alpha[b,i]-O_ref[b,i])) / I_abs[b]

分母为0时记录NA，不随意添加epsilon。

额外保存：

- 输出误差分子。
- 输入绝对值分母。
- 参考累计输出绝对总量。
- 有符号累计输出差异。
- 以参考累计输出为分母的辅助指标。

主要门槛使用原R5定义，不改变归一化口径。

### 9.3 动力学分解

计算逐神经元：

- D_leak
- D_reset
- D_res
- Delta_D_leak
- Delta_D_reset
- Delta_D_res
- Delta_O

分别报告有符号均值、绝对值均值、中位数、P90、P95。

保存每个样本的聚合统计。

保留足够的原始统计量，明确哪些指标可以独立复算。

必须分别保存R1、R2残差及有效输入一致性结果。

不保存整个数据集的巨大高维膜电位张量；优先按Batch流式处理。

### 9.4 脉冲翻转和静默

R6：

F_flip = count(s_alpha != s_ref)/total_neuron_time_states

分开统计1->0和0->1事件数。

定义：

K_ref[b,i] = sum_t(s_ref[t,b,i])

K_alpha[b,i] = sum_t(s_alpha[t,b,i])

R7：

F_silent = count(K_ref>0 and K_alpha==0)/count(K_ref>0)

保存分子及分母。

注意阈值提高可能通过重置轨迹改变产生0->1事件，不能假定所有变化都是脉冲删除。

### 9.5 任务性能

原模型TET=False。

最终输出的逻辑形状为[T,B,C]。

z[b,c] = mean_t(logits[t,b,c])

loss[b] = CrossEntropy(z[b,:],label[b])

R8：

Delta_loss[b] = loss_alpha[b]-loss_ref[b]

保存逐样本损失、预测类别、正确性和样本ID。

不能以逐时间步交叉熵的平均替代上述定义。

同时报告准确率变化，主要任务指标为配对交叉熵差异。

### 9.6 统计方法

固定2000次样本级配对Bootstrap，随机种子2027。

报告95%百分位置信区间。

对于整体FR和恢复比例等指标，在每次重采样后重新计算整体分子、分母或均值。

不要先计算逐神经元恢复比例再平均。

不要将神经元位置视为独立统计样本。

报告NA和无效重采样数量。

置信区间只描述当前固定训练模型及诊断样本的不确定性，不代表训练随机种子间的稳定性。

### 9.7 H-001原预注册判定条件

主要模块、alpha=1.5：

- R_FR >= 0.20。
- mean(E) >= 0.05。
- mean(E)的95% CI下界 > 0.05。
- R1、R2数值检查通过。
- 有效输入一致性及alpha=1.0控制通过。

以上条件满足时，报告达到H-001预设推进门槛。

若R_FR>=0.20且mean(E)的95% CI上界<0.05，则报告当前条件下反对具有实际幅度的H-001。

若干预不足、CI过宽或指标无效，则报告证据不足。

其他alpha和模块只属于补充探索，不允许替代主要检验。

进入EXP-003还必须满足：

mean(Delta_loss)>=0.02 nats，且配对95% CI下界>0。

任务损失增加不是H-001本身成立的必要条件，只是开展H-002诊断的进入门槛。

## 十、EXP-003：累计输出补偿反事实实验

G2：theta=1.5*theta_ref，参考累计输出引导的幅值补偿。

### 10.2 原始反事实公式

eligible[b,i] = (K_ref[b,i]>0) AND (K_alpha[b,i]>0)

R10：

若eligible：

c[b,i] = clip(O_ref[b,i]/O_alpha[b,i],0.25,4.0)

否则：

c[b,i] = 1.0

R9：

o_cf[t,b,i] = c[b,i]*o_alpha[t,b,i]

补偿系数沿时间维度广播。

只在ATLIF原始前向结束后、输出传递给下游网络的边界实施补偿。

不得改变该模块自身m、u、s或重置机制。

不得增加额外脉冲。

正阈值条件下，eligible位置的O_alpha应为正。

若出现非正或非有限值，报告异常，不通过任意epsilon掩盖。

本方法只是依赖参考模型输出的机制诊断工具，不是独立可部署的创新方法。

### 10.3 随机补偿对照

G3在每个样本、同一个模块内，只对eligible位置的c进行随机置换。

随机种子2028。

使用独立随机生成器，不污染模型状态或其他实验组。

按固定样本顺序记录置换生成规则，保证重复执行可追溯。

置换保留补偿系数分布，不使用类别标签。

若eligible元素不足2个，记录该样本无法形成有效随机对照。

报告置换前后真正发生变化的系数比例。

### 10.4 必须通过的因果控制检查

完整逐元素检查：

s_G1 == s_G2 == s_G3

同时检查：

m_G1 == m_G2 == m_G3

u_G1 == u_G2 == u_G3

膜电位采用预先记录的数值容差，二值脉冲必须完全一致。

受干预模块的有效输入必须一致。

G2和G3仅改变下游接收的脉冲幅值，下游模块的膜电位和脉冲状态允许自然改变。

R1、R2适用于原ATLIF内部动力学输出，不要求额外的反事实下游输出仍满足原动力学恒等式。

### 10.5 评价指标

对所有组保存：

- per-sample loss。
- accuracy。
- 原始脉冲发放率。
- 累计输出误差。
- 脉冲及膜电位一致性。

R11：

R_E = (mean(E_G1)-mean(E_G2))/mean(E_G1)

R12：

R_loss = (mean(loss_G1)-mean(loss_G2))/(mean(loss_G1)-mean(loss_G0))

如果任务损失增量非正或过小，不使用R_loss，标记NA。

同时计算：

Gain_G2_vs_G1 = mean(loss_G1-loss_G2)

Gain_G2_vs_G3 = mean(loss_G3-loss_G2)

使用2000次样本级配对Bootstrap，seed=2027。

保持G0至G3的逐样本配对索引。

### 10.6 新增辅助理论指标R14

理论版本v0.1.2。

定义：

A[b] = eligible位置集合。

不可恢复误差下界：

E_floor[b] = sum_{i not in A[b]}(
    abs(O_alpha[b,i]-O_ref[b,i])
) / I_abs[b]

注意该下界基于原定非eligible位置保持c=1的补偿规则。

对于有效的正分母：

R14：

R_E_max = 1-mean(E_floor)/mean(E_G1)

R_E_max是当前补偿规则下累计输出误差恢复比例的理论上界。

同时报告：

- eligible位置占比。
- 原参考活动位置中的补偿覆盖率。
- 新增静默比例。
- 参考静默但干预后发放的比例。
- 系数截断比例。
- 补偿系数分布。
- E_floor。
- R_E_max。
- 实际R_E与理论上界的差异。

检查实际E_G2是否不低于E_floor，实际R_E是否不超过理论上界（允许合理浮点误差）。

该指标只属于辅助机制分析，不改变原H-001/H-002预注册门槛。

若R_E_max<0.50，说明原定50%恢复门槛在当前反事实干预下不可实现。

此时不能仅依据任务损失未恢复否定H-002，应报告该干预的可恢复性限制。
