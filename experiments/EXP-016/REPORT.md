## 完整模型与有效连接机制

随机初始化 CifarNet 输出形状 `[4,256,10]`，36,720,484 参数，任务前向/反向有限，SGD lr 0.1 / momentum 0.9 / weight_decay 0；权重阈值为 buffer，BN affine 在优化器中。作者监视器可运行。完整模型局部惩罚检查中 7 个卷积阈值及 6 个 BN affine 模块实际变化、任务梯度得以恢复、惩罚 buffer 清零，非零阈值探针使连接数 6912 降至 596；这些是 SMOKE_TEST，不是训练后压缩指标。

同活动率、同名义扇出的两个通道，名义系数均为 9，真实有效扇出分别为 9 和 1；单脉冲删除的真实边际 SOP 依次为 9 和 1。R60 与显式连接枚举、可比较时作者 monitor 一致，R61 单脉冲测试通过；边界、stride=2、dilation、非方形输入与分组公式测试见 connectivity_cost_tests.json，分组测试不表示官方 SparseConv2d 支持 groups>1。边界使 R59 近似偏离精确空间计数，不应将其视为普适等式。

作者聚合示例：批次总数 8/3、实际样本数 4/2 时，原作者按固定 batch size 的值为 1.375，按实际样本数加权为 1.8333；原 monitor 对非二值输入直接求和。CifarNet 中 activation2/activation5 后有池化，activation5 后还有 flatten，不能未经修正套用直接卷积通道扇出。

四次 GPU 进程墙钟加 CUDA 库探针墙钟约 26.15 秒，包含启动，是 GPU 使用的保守计数；有记录的 CPU 脚本计时合计约 16.68 秒，不含部分导入及安装准备，无法声称是完整累计 CPU。未触碰官方测试集，未做完整训练、额外搜索或 ECAS 方法训练。
