# 局限与审计

- 同一父模型和单一开发验证集，随机集合并非独立训练种子。75% 是辅助。
- 正式测试集未读取；D_grad/D_cal 均来自父模型训练集，D_cal 仅对本次拟合独立。
- RUN-001 的预检汇总检查数量错误，真实检查均已执行，已停止并保存；RUN-002 完全重做且累计资源。
- 准入前 R120 在真实网络、固定人工删除 1024 个神经元及人工非零补偿下检查全部非目标状态、隐藏脉冲及 logits；并未逐一对最终选择的 50% 和 75% R1/R3 模型执行独立的脉冲逐元素比较。这一验证范围缺口使对应严格准入条件不能被视作完整通过；最终性能为已执行的探索性结果，不可视作全部门槛已满足。
- CPU 进程树计数开始于 Python 导入之后；其他审查命令未全程计数，早期 60 秒为预算预留而非测量。GPU 墙钟是受控进程时长的保守代理，不是硬件能耗或核执行时间。
- 如无逐样本 SOP，SOP 配对区间标记 NA。
